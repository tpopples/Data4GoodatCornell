# Historic Redlining Indicator (HRI2020)

This repository contains a copy of the **Historic Redlining Indicator (HRI2020)** dataset used for mapping historic redlining patterns across U.S. census tracts.

## Data Source

Meier, Helen C. S., & Mitchell, Bruce. (2023).  
**Historic Redlining Indicator for 2000, 2010, and 2020 U.S. Census Tracts.**  
ICPSR Study 141121.  Data avialable here.
[https://doi.org/10.3886/E141121V3](https://doi.org/10.3886/ICPSR141121.V3)


## Description

The HRI dataset overlays historical Home Owners’ Loan Corporation (HOLC) redlining grades onto modern U.S. census tracts.  
Each tract receives a score based on the share of land area historically graded:

- A – Best
- B – Still Desirable
- C – Definitely Declining
- D – Hazardous
